# Техническа документация – компютърна конфигурация (бюджет 4 688 €)

Практическа задача: кандидатствали сме по европейски проект за компютърна конфигурация и сме одобрени за финансиране.

## Готови файлове
- `Техническа_документация.docx` – за редакция в Word
- `Техническа_документация.pdf` – за предаване

## Какво съдържа
1. Увод и изисквания към конфигурацията
2. Хардуерни компоненти – описание, производител и обосновка за всеки компонент
3. Финансов анализ – количествено-стойностна сметка с ДДС, разпределение по категории, сравнение с алтернативи
4. Заключение и източници

Форматиране: A4, Times New Roman 12 pt, двустранен печат (огледални полета, номер на страницата отвън), абзаци с отстъп 1,25 cm, номерирани фигури и таблици, автоматично съдържание.

## Преди предаване
- Попълнете полетата в `[квадратни скоби]` на заглавната страница (име, клас, училище, проект).
- Цените са ориентировъчни (октомври 2026 г.) – при нужда ги сменете в `src/data.json` и генерирайте отново.
- В Word: при отваряне потвърдете „Обновяване на полетата“, за да се обнови съдържанието. После **Файл → Запиши като → PDF**, за да е PDF-ът с истински Times New Roman.

## Повторно генериране
```bash
python3 src/charts.py      # фигури (matplotlib)
node src/build.js          # DOCX (docx-js)
python3 src/finalize.py    # огледални полета, съдържание, PDF (LibreOffice)
```
